# 安得家政 CRM Mobile App UI/UX 视觉规范 (UI Guidelines)

## 1. 颜色规范 (Colors)
- **品牌主色 (Primary)**: `#158F82` (翠绿色) —— 用于主按钮、重要状态高亮、选中态。
- **品牌辅色/点缀**:
  - **浅绿背景 (Primary Light)**: `rgba(21, 143, 130, 0.04)` 或 `rgba(21, 143, 130, 0.08)` —— 用于选中状态卡片的底色、微标签背景。
  - **警告/危险 (Danger)**: `#ff3141`
  - **高亮数字 (Orange)**: `#FF8F1F` —— 用于突出薪资、金额等数字。
- **背景色 (Background)**:
  - **页面底层 (Base Background)**: `#f5f7fa` (浅灰蓝色) —— 确保不是死白，让卡片有悬浮感。
  - **卡片/内容区 (Surface)**: `#ffffff` (纯白)。
  - **输入框容器/只读容器**: `#f7f8fa` (更浅的灰底，无边框设计)。
- **文字颜色 (Text)**:
  - **主标题/强调用字 (Heading/Strong)**: `#1a1a1a` 或 `#333333`。
  - **次要文字/描述 (Secondary)**: `#666666`。
  - **提示占位符/极弱文字 (Placeholder/Hint)**: `#999999` 或 `#cccccc`。

## 2. 卡片与布局 (Cards & Layout)
废弃 `antd-mobile` 默认的横向贯通列表（List / List.Item 默认样式）。
全面启用**卡片化布局 (Card UI)**。

- **外边距/内边距**: 
  - 页面左右通常留白 `12px` 或 `16px`。
  - 卡片内边距通常为 `16px`（较紧凑用 `12px`，大区域用 `20px`）。
- **圆角 (Border Radius)**: 
  - **大卡片/主容器**: `16px` (有时为了更圆润可使用 `20px`)。
  - **输入框/内部小卡片**: `6px` 或 `8px`。
  - **胶囊按钮/微标签**: `24px` 或 `20px`。
- **阴影 (Box Shadow)**: 
  - 采用大厂高级微弥散阴影，禁忌浓重黑影。
  - **基础卡片阴影**: `0 2px 12px rgba(0,0,0,0.04)`。
  - **点击/选中强化阴影**: `0 4px 16px rgba(21, 143, 130, 0.12)`。
- **边框 (Borders)**:
  - 尽量不用生硬的 `#eee` 实线边框，用背景色差(`fff` on `#f5f7fa`)区分层级。
  - 选中态可使用主色边框：`1.5px solid #158F82`。

## 3. 字体排版 (Typography)
- **字号 (Font Size)**:
  - 大标题/人名: `18px` 或 `20px` (配合 `fontWeight: 600`)。
  - 常规标题/分组标题: `15px` 或 `16px` (配合 `fontWeight: 500/600`)。
  - 正文/输入内容: `14px`。
  - 次要说明/时间: `12px` 或 `13px`。
- **字重 (Font Weight)**:
  - 重要信息一律用 `600`。
  - 按钮文字建议用 `500`。

## 4. 交互组件规范 (Components)
- **按钮 (Buttons)**:
  - 统一使用胶囊形态 (`borderRadius: 24px`)。
  - 次要按钮使用 `fill="outline"`，但颜色应调为主色（通过 `--border-color` 和 `--text-color` 变量）。
- **搜索框 (SearchBar)**:
  - 药丸形状，灰底 (`#f5f5f5`)，无边框，融于背景。
- **弹层 (Popup)**:
  - 底部弹层应有 `borderTopLeftRadius` 和 `borderTopRightRadius`（例如 `16px`）。
  - 弹层内部列表必须同样遵循卡片化或去线化（去掉默认 `List` 的 border）。
- **微标签 (Tags)**:
  - 废弃默认方角/直角 Tag。
  - 使用自绘 `div`，大圆角 (`border-radius: 20px`)，半透明背景 (`rgba(主色, 0.1)`)，主色文字，没有实线边框。

## 5. 核心原则
- **留白呼吸感**：不要让信息堆砌，用 Padding 拉开间距。
- **去线化**：能用色块、阴影区分的，绝不用线条。
- **信息层级分明**：一眼看过去要知道什么是名字（粗大）、什么是说明（细灰）、哪里能点（主色/胶囊）。
