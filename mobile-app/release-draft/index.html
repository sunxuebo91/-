系统要求

支持 Android 7.0（API 24）及以上 系统的手机 / 平板。iOS 设备暂不支持。

安装步骤

  1. 点击上方按钮下载 APK
    下载完成后可在浏览器下载列表或「文件管理器 → Download」中找到安装包。
  2. 允许「安装未知应用 / 未知来源」
    首次安装系统会弹窗提示。若未自动弹出，可到：
    设置 → 应用 → 特殊访问权限 → 安装未知应用 → 选择你使用的「浏览器 / 文件管理器」→ 打开「允许来自此来源」。
    （不同品牌与 Android 版本入口措辞略有差异，思路一致。）
  3. 打开 APK 完成安装
    点击下载好的安装包，按提示点「安装」，完成后点「打开」。
  4. 首次打开并登录
    使用你现有的 CRM 员工账号登录即可，无需额外注册。
如安装被系统或安全软件拦截，请确认安装来源为「公司内部分发页」（本页面）后再继续；请勿从非官方渠道下载安装包。

如何获取更新

  • App 会在启动或「我的 → 关于 → 检查更新」时自动检测新版本。
  • 发现新版本时按提示「下载并安装」，App 会在内部下载更新包并唤起系统安装，登录状态与数据不受影响。
